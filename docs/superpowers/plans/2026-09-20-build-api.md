**Goal:** A token-authenticated REST API that lets an AI (or any client) build LayerNexus
projects **iteratively** — one small, validated step at a time (create project → add module →
add/attach part → upload STL → attach document → assign hardware), reading current state between
steps. Each op is granular so a partial failure is fixable in place, not "delete everything and
retry". Scope: projects, sub-project composition edges, parts (+STL upload), documents, hardware.
**Out of scope (do NOT add):** print jobs, queue, printers, moonraker.

**Architecture:** Django REST Framework layer in a new `core/api/` package, mounted at
`/api/v1/`. Per-user token auth (DRF `TokenAuthentication`) so the token's user carries the
existing RBAC — write ops require `core.can_manage_projects` (same as the UI `ProjectManageMixin`);
reads require authentication. All create/attach ops reuse the merged Phase 1–4 edge model
(`ProjectComponent`/`ProjectPart` with the cycle guard) and return structured validation errors so
the client self-corrects. Idempotency: edge attaches use `get_or_create` (unique constraints);
creates accept an optional `client_ref` to dedupe retries.

**Tech Stack:** Django 6.0, **Django REST Framework (new dependency)**, Python 3.13, SQLite,
ruff 0.15.20, Django test runner (DRF `APITestCase`).

**Design decisions (approved):** DRF; per-user tokens (RBAC applies); iterative/granular; scope
excludes printing. STL upload is a dedicated multipart endpoint that, after saving the file,
triggers the same background estimation the UI does. **Honest caveat baked into docs:** the API
builds structure/BOM + attaches STL files; it does not generate 3D geometry.

## Endpoint surface (`/api/v1/`)

- **Projects:** `GET/POST /projects/`, `GET/PATCH/DELETE /projects/{id}/`,
  `GET /projects/{id}/tree/` (nested assembly: children+parts+hardware, for orientation).
- **Components (sub-projects):** `POST /projects/{id}/components/` `{child_project, quantity}`
  (cycle-guarded), `DELETE /projects/{id}/components/{edge_id}/`, `PATCH` quantity.
- **Parts:** `GET/POST /parts/` (all writable fields), `GET/PATCH/DELETE /parts/{id}/`,
  `POST /parts/{id}/stl/` (multipart file → sets `stl_file`, triggers estimation).
- **Project↔part edges:** `POST /projects/{id}/parts/` `{part, quantity}`, `DELETE .../{edge_id}/`, `PATCH` qty.
- **Documents:** `POST /projects/{id}/documents/` (multipart), `GET` list, `DELETE .../{id}/`.
- **Hardware:** `GET/POST /hardware-parts/` (catalog), `POST /projects/{id}/hardware/`
  `{hardware_part, quantity}`, `DELETE .../{id}/`.
- **Auth:** token created via `manage.py create_api_token <username>` (Task 1).

- [ ] **Step 2: Permission class** (`core/api/permissions.py`):

```python
from rest_framework.permissions import BasePermission, SAFE_METHODS


class ReadOrProjectManage(BasePermission):
    """Read for any authenticated user; writes require can_manage_projects (UI-parity RBAC)."""

    def has_permission(self, request, view) -> bool:
        if request.method in SAFE_METHODS:
            return bool(request.user and request.user.is_authenticated)
        return bool(request.user and request.user.has_perm("core.can_manage_projects"))
```

- [ ] **Step 5: Auth test** (`core/tests/test_api_auth.py`, `APITestCase`):

```python
from rest_framework.authtoken.models import Token
from rest_framework.test import APITestCase
from django.contrib.auth.models import Group, User


class ApiAuthTests(APITestCase):
    def test_unauthenticated_is_401(self):
        resp = self.client.get("/api/v1/projects/")
        self.assertIn(resp.status_code, (401, 403))

    def test_token_auth_grants_read(self):
        u = User.objects.create_user("apiuser", password="x")
        token = Token.objects.create(user=u)
        self.client.credentials(HTTP_AUTHORIZATION=f"Token {token.key}")
        resp = self.client.get("/api/v1/projects/")
        self.assertEqual(resp.status_code, 200)

    def test_write_requires_manage_perm(self):
        u = User.objects.create_user("reader", password="x")  # no groups → no manage perm
        token = Token.objects.create(user=u)
        self.client.credentials(HTTP_AUTHORIZATION=f"Token {token.key}")
        resp = self.client.post("/api/v1/projects/", {"name": "X"}, format="json")
        self.assertEqual(resp.status_code, 403)
```
